# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-12

Первый публичный выпуск.

### Добавлено

- Все 62 метода справочника API Haskimail: отправка, шаблоны, сообщения, возвраты, серверы, каналы, домены,
  статистика, вебхуки, правила для входящих, стоп-листы.
- `IServersApi.IssueTokenAsync(serverId, request?)` — выпуск дополнительного серверного
  API-ключа (`POST /servers/{id}/tokens/new`); открытое значение ключа возвращается один раз.
  Необязательное `IssueServerTokenRequest.Name` — название ключа.
- Разбор и проверка подписи всех вебхуков: доставка, возврат, открытие, клик, жалоба, изменение подписки, входящие письма.
- Платформы: netstandard2.0 (.NET Framework 4.6.2+), net8.0, net10.0. Совместимость с Native AOT и триммингом.
- Повторы при временных ошибках без риска дублей отправки, таймауты, учёт `Retry-After`.
- Иерархия исключений по типам ошибок, все коды ошибок API в `HaskimailErrorCodes`.
- Проверка документированных лимитов до отправки.
- Автопагинация через `IAsyncEnumerable`, интерфейсы для моков, расширяемые enum.
- Пакет `Haskimail.NET.Extensions.DependencyInjection` с `AddHaskimail`.
- `TemplatePlaceholders`, `HaskimailTestAddresses`, `SendResultExtensions`.
- `Template.DecodedName`, `Template.DecodedSubject`, `TemplateSummary.DecodedName`.

### Исправлено

- Входящие письма (поиск, детали, обход правил, повтор) отправляли ключ аккаунта, если ключа сервера нет, — сервер отвечал 401.
  Теперь эти методы требуют ключ сервера и без него сразу выбрасывают `InvalidOperationException`.
- Получение, изменение, удаление и список шаблонов работали только с ключом сервера, хотя API принимает и ключ аккаунта
  (как уже работало создание). Теперь — любым ключом.
- `UpdateAsync` с функцией-правкой и `UpdateTemplateRequest.FromTemplate` отправляли обратно название и тему как есть;
  если они приходили HTML-экранированными, каждая правка экранировала их ещё раз («&» → «&amp;amp;»). Теперь они раскодируются перед сохранением.
- Дата `0000-00-00 00:00:00` в ответе ломала разбор всего ответа; теперь читается как `null`.

### Удалено

- `EnableSmtpApiErrorHooks` из запросов создания/изменения сервера — поле отсутствует в API
  и игнорировалось.
